# Stock Portfolio Tracker

A simple console-based Stock Portfolio Tracker built using Python.

## Features

- Displays available stocks and their prices
- Allows users to select stocks
- Accepts the quantity of shares
- Calculates investment for each stock
- Calculates total portfolio investment
- Saves the portfolio result to a text file

## How to Run

1. Download or clone this repository.
2. Open the project folder in a Python IDE or terminal.
3. Run the following command:

```bash
python stock_portfolio_tracker.py

AAPL - $180
TSLA - $250
GOOGL - $150
MSFT - $420
AMZN - $190

Enter stock name (or 'done' to finish): AMZN
Enter quantity: 2
AMZN: 2 shares × $190 = $380

Enter stock name (or 'done' to finish): done

===== PORTFOLIO SUMMARY =====
AMZN | Quantity: 2 | Price: $190 | Investment: $380

Total Investment: $380

Portfolio result saved to portfolio_result.txt
```text
